# Kuromi Codex Pet — Installation Guide
This is **Kuromi**, a desktop pet generated and powered by Codex.

## Manual Installation
1. Extract this package.
2. Copy the extracted `kuromi` folder to:
    %USERPROFILE%.codex\pets
3. Open Codex, then enable it via **Settings → Appearance → Pet**.
> **Tip:** If Codex is already running when you copy the files, simply refresh the pet panel or restart Codex to see it appear.



## Automatic Installation (Recommended)
You can also hand the zip file directly to Codex and say:
> *Help me install this pet.*
Codex will then automatically:
    Extract the `kuromi` folder from the archive to `%USERPROFILE%\.codex\pets`
Once finished, restart Codex or refresh the pet panel to activate it.
